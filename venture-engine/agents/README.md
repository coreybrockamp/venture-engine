# Agent Handoff Chain

`SCOUT → PROBLEM CLUSTERER → MARKET ANALYST → OPPORTUNITY GENERATOR → OPPORTUNITY SCORER → EXPERIMENT DESIGNER → EXPERIMENT ANALYST → INVESTMENT COMMITTEE`

This is not forced: Clusterer → Scout for more evidence; Market Analyst → Scout for weak customer evidence; Scorer → Market Analyst for missing economics; Analyst → Designer for ITERATE/RETEST; Committee → PAUSE or KILL. Each agent may modify only its listed Outputs.
