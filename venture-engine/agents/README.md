# Agent Handoff Chain

`COMMERCIAL FRICTION DISCOVERY (manual pre-Scout triage) → approved persona/workflow → SCOUT → PROBLEM CLUSTERER → MARKET ANALYST → OPPORTUNITY GENERATOR → OPPORTUNITY SCORER → EXPERIMENT DESIGNER → EXPERIMENT ANALYST → INVESTMENT COMMITTEE`

Commercial Friction Discovery is not a canonical evidence stage. It creates a human-reviewed target-selection card only; Scout independently creates the first canonical observations after a candidate is authorized.

This is not forced: Clusterer → Scout for more evidence; Market Analyst → Scout for weak customer evidence; Scorer → Market Analyst for missing economics; Analyst → Designer for ITERATE/RETEST; Committee → PAUSE or KILL. Each agent may modify only its listed Outputs.
