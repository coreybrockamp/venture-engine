# Automation Runbooks

These are ready-to-use prompts, not active schedules. Create each scheduled task from Codex desktop or ChatGPT Work after first testing its prompt in a normal task. Use a **standalone project task** for independent periodic work; select this project and prefer an isolated worktree if it is a Git repository. Use a thread heartbeat only when continuity of the current conversation is necessary.

Codex’s schedule UI accepts natural-language schedules and advanced RFC 5545 recurrence rules. Suggested cadence: daily scout; daily experiment monitor only when tests exist; competitor watch every 1–2 days; clustering/generation every 3 days; weekly committee and experiment proposal; monthly rescan. Configure notifications for meaningful changes, completion, failure, or required approval—not routine empty runs.

Before enabling: verify the task can access the project, paste the matching runbook prompt, confirm no external spending/publishing is authorized, and inspect the first runs. See [official scheduled-task documentation](https://learn.chatgpt.com/docs/automations) for current UI and scheduling behavior.
