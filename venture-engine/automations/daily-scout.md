# Daily Scout Runbook

Schedule: daily, weekday morning. Skip if no persona has a documented evidence gap.

Read root `AGENTS.md`, `SYSTEM_STATUS.md`, source configuration, and `agents/scout.md`. Select one active persona with the greatest evidence gap. Gather only legally accessible, revisitable public evidence. Append deduplicated `OBS-*` records, then validate. Update a dated daily report only when observations or meaningful research gaps changed; otherwise remain quiet. Never create a problem from one comment, invent sources, publish externally, contact people, or spend money.
