# Clustering and Opportunity Generation Runbook

Schedule: every 3 days.

Read new observations first. Run the clusterer before the generator: deduplicate, establish independent support, update valid `PROB-*` records, and document contradictions. Generate only a small number of opportunities for strong problems, score them using the rubric, and create a research memo only for scores of 70+. Validate records and add a report only if a state changed. Do not create speculative idea lists or launch tests.
