# CFD Historical Recall Calibration

This directory contains retrospective simulations, not live CFD cards or canonical research. Each simulation applies `manual-pilot-v2` without changing it, labels sources by cutoff status, and separates a simulated decision from the company’s later outcome. It must not be cited as an Observation, Problem, Opportunity, willingness-to-pay proof, or live CFD result.

The eight cases were selected for workflow and buyer variation rather than user context: five commercially significant operational-workflow positives, two harder category-creation/early-evidence positives, and one failed control. Cutoff evidence alone controls the simulated decision.

`AUTHORIZE_SCOUT` requires all seven current conditions; `HOLD` preserves a plausible but incomplete case; `REJECT` means the pre-cutoff evidence does not support a live-CFD candidate. Historical success never upgrades the simulation.
