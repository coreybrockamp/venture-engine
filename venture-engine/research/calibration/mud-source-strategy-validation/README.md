# MUD Source-Strategy Historical Validation

This non-canonical replay applies the committed bounded MUD source strategy to the five expanded-calibration cases that originally received `HOLD`: Warby Parker, Kiva, Wix, Canva, and Dropbox. It tests evidence acquisition only. Original cards, cutoff dates, labels, and official decisions remain unchanged.

Only `PRE_CUTOFF_DIRECT` and `PRE_CUTOFF_INDIRECT` evidence can affect a replay decision. `POST_CUTOFF_OUTCOME_ONLY` and `UNUSABLE_HINDSIGHT` remain excluded. Per case, the replay used at most four query rounds, twelve opened URLs, and three source-family attempts, including a targeted second-family pivot before an observability conclusion. A replay `AUTHORIZE_SCOUT` would remain historical only and would never authorize live Scout.

The cards contain lightweight Markdown source ledgers, roles, independence groups, gate results, and gap labels. No JSONL, schema, canonical entity, controller, CFD, or MUD implementation changed.
