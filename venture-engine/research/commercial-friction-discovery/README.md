# Commercial Friction Discovery Cards

This directory holds manual, human-reviewed Commercial Friction Discovery (CFD) candidate cards. Use [TEMPLATE.md](TEMPLATE.md) for a dated card.

Cards are pre-Scout hypotheses for target selection, not canonical customer evidence. They must not be cited downstream as formal Observations, Problems, Opportunities, or willingness-to-pay proof. A separately authorized Scout pass must independently verify the source and persist any qualifying evidence under the normal Scout rules.

The pilot is manual only. It has no schema, JSONL store, candidate ID system, numeric ranking, autonomous learning, scheduled search, or automatic persona/Scout authorization.
